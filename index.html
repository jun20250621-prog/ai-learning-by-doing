Week 1 - LLM API 基礎

⏱ 30 分鐘🏷️ Python · API

📌 專案目標

學會呼叫 OpenAI API，建立第一個 AI 應用

🔧 預備知識

  • Python 基礎語法
  • API 概念

1. 申請 OpenAI API Key

  • 前往 OpenAI Platform
  • 註冊並取得 API Key

2. 安裝 SDK

pip install openai

3. 第一個 AI 程式

import openai
openai.api_key = "你的 API Key"
response = openai.ChatCompletion.create(
    model="gpt-3.5-turbo",
    messages=[
        {"role": "system", "content": "你是一個天氣助手"},
        {"role": "user", "content": "今天台北天氣如何？"}
    ]
)
print(response.choices[0].message.content)

Week 2 - Prompt Engineering

⏱ 40 分鐘🏷️ Prompt · 優化

📌 專案目標

學會設計有效的提示詞，打造文章摘要工具

🔧 預備知識

  • 完成 Week 1
  • 了解 JSON 結構

1. Prompt 基礎概念

  • System Prompt：設定 AI 角色
  • User Prompt：具體問題

2. 基本摘要 Prompt

response = openai.ChatCompletion.create(
    model="gpt-3.5-turbo",
    messages=[
        {"role": "system", "content": "你是一個專業的文章摘要助手"},
        {"role": "user", "content": "請用 3 句話摘要以下文章：\n\n" + article_text}
    ]
)

3. Few-Shot Prompting

messages=[
    {"role": "user", "content": "文章：AI 正在改變世界\n分類：科技"},
    {"role": "user", "content": "文章：今天天氣真好\n分類：生活"},
    {"role": "user", "content": "文章：股票市場下跌\n分類：？"}
]

Week 3 - Embedding + 向量

⏱ 45 分鐘🏷️ Embedding · 向量資料庫

📌 專案目標

學會使用 Embedding，將文字轉為向量，實現語意搜尋

1. 什麼是 Embedding？

  • 文字 → 數字向量（捕捉語意）
  • 相似的文字會有相似的向量

2. 安裝套件

pip install langchain langchain-openai langchain-text-splitters

3. 文字分割與 Embedding

from langchain.text_splitter import CharacterTextSplitter
from langchain_openai import OpenAIEmbeddings
chunks = text_splitter.split_text(long_article)
doc_embeddings = embeddings.embed_documents(chunks)

Week 4 - RAG 實作

⏱ 45 分鐘🏷️ RAG · LangChain

📌 專案目標

實作 RAG（檢索增強生成），讓 AI 根據文件回答問題

1. RAG 流程

使用者問題 → 檢索相關文件 → 生成回答

2. 安裝 LangChain

pip install langchain langchain-community faiss-cpu

3. 簡易 RAG 實作

from langchain_community.vectorstores import FAISS
from langchain.chains import RetrievalQA
db = FAISS.from_documents(texts, OpenAIEmbeddings())
qa = RetrievalQA.from_chain_type(llm=llm, retriever=db.as_retriever())
answer = qa.run(question)

Week 5 - Agent 基礎

⏱ 45 分鐘🏷️ Agent · Tools

📌 專案目標

學會建立 AI Agent，賦予 AI 使用工具的能力

1. 什麼是 Agent？

  • Agent = LLM + Tools + Memory
  • 能自主規劃並執行任務

2. 安裝 LangChain Agent

pip install langchain langchain-openai duckduckgo-search

3. 第一個 Agent

from langchain.agents import AgentType, initialize_agent
agent = initialize_agent(
    tools=[search],
    llm=llm,
    agent=AgentType.ZERO_SHOT_REACT_DESCRIPTION
)
result = agent.run("2024 年最新的 iPhone 型號是什麼？")

Week 7 - Fine-tuning 入門

⏱ 50 分鐘🏷️ Fine-tuning · LoRA

📌 專案目標

學會使用 LoRA 微調模型，打造專屬 AI

1. 為什麼要 Fine-tuning？

  • 預訓練模型：通用知識
  • 微調：特定領域知識
  • LoRA：省資源的微調方法

2. 安裝套件

pip install transformers peft accelerate

3. LoRA 微調

from peft import LoraConfig, get_peft_model
lora_config = LoraConfig(r=8, lora_alpha=16, target_modules=["q_proj", "v_proj"])
model = get_peft_model(model, lora_config)

Week 8 - 部署上線

⏱ 45 分鐘🏷️ Docker · 部署

📌 專案目標

將 AI 服務 Docker 化並部署上線

1. 為什麼用 Docker？

  • 環境一致性
  • 輕量級虛擬化
  • 易於部署與擴展

2. 建立專案結構

ai-service/
├── app/
│   └── main.py
├── Dockerfile
└── requirements.txt

3. Dockerfile

FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
CMD ["uvicorn", "app.main:app", "--host", "0.0.0.0"]
